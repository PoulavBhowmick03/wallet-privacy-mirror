Model comparison (optional)

Sends the analyzed transactions to OpenAI and asks a model to propose additional patterns. The model can only cite transaction IDs. Code checks each proposal against those transactions and writes the text you see.

Limitations

  • An address is not an identity. This report does not establish names, employers, or locations.
  • Regular transfers can have many explanations. A pattern does not establish a payment's purpose.
  • Only successful ETH transfers and USDC, USDT, and DAI transfers are included. Other tokens, internal calls, fees, and other chains are excluded.
Method and data handling
Reports are held in server memory for up to 15 minutes. No database, analytics, or wallet connection.

This sends the analyzed transaction addresses, amounts, timestamps, evidence IDs, and recurring-transfer candidates to OpenAI. Hosted analysis creates another disclosure.

The model can select existing hypotheses and propose amount or timing patterns. Code checks each proposal against the cited transfers. It cannot establish identity or payment purpose. This request can incur an API charge.
